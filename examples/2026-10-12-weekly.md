# 2026-10-12 ~ 2026-10-18 周报

## Mega-reth txpool 升级与定制逻辑迁移

本周主线是将 MegaETH txpool 适配到 reth v2.3.0，并把 MegaETH 专属行为从通用交易池中分离。工作从 vendor 上游版本推进到直接依赖上游 git 版本，移除了 26,815 行 vendored 代码；准入校验、sender 校验、账户 slot 诊断、交易池维护与过期交易驱逐、executor 交易流也逐步迁入 `megaeth-txpool`。

同一升级工作流还包括三项配套调整：`minimal_protocol_fee` 默认值与 MegaETH base fee 下限对齐；MiniRex 的 code-size 限制通过 EVM 配置传递；校验 worker 在执行交易验证前释放接收端锁。维护循环副本补回 account-reload 日志，并移除了多余的 Osaka sidecar 转换。

准入策略方面，曾实现“fee cap 低于下一块 base fee 时拒绝交易”，随后回退。原因是 `next_block_base_fee` 在 MegaETH 上不是动态拒绝阈值；链上 basefee 为 `1_000_000`，由 L1 部署合约保证。当前保留的是配置层的最低协议费用兜底。pending-pool broadcast 则改由 sibling wrapper 隔离，并订阅交易池原生 broadcast，避免继续修改上游 pool。

PR #2482 的 reth v2.3.0 re-fork review 未发现阻塞问题。PR #2489 的推送被 `non_fast_forward` 规则拒绝，远端没有变化；等价版本仍在本地。C2 需要修改 L1 部署参数，PR #2489 后续采用原提交还是 squash 尚待决定。

## Mega-reth CLI 与 RPC 行为修正
